# 慧眼辨伪

面向 AI 生成图像与深度伪造图像检测的大学生创新创业训练项目。

## 项目背景

随着 AIGC 技术的发展，AI 生成图像与深度伪造图像日益普及。虚假影像可能被用于编造新闻、网络诈骗和恶意造谣。本项目聚焦网络视觉安全，研究图像真伪识别与可疑区域分析，为识别图片造假提供技术支持。

## 研究目标

- 研究 AI 生成图像、深度伪造图像与真实拍摄图像之间的差异。
- 分析纹理异常、细节断层、光影违和等可能的伪造线索。
- 构建并评估图像检测模型，提高对不同来源图像的泛化能力。
- 探索可疑区域定位、特征解释和生成来源分析。

以上为研究计划，具体功能与效果以实验验证为准。

## 技术方向

1. 数据准备：收集具有明确来源与使用许可的真实图像和伪造图像，完成清洗与数据集划分。
2. 基线实验：建立图像分类基线，记录准确率、精确率、召回率、F1 和 AUC 等指标。
3. 模型研究：结合深度学习与图像细节特征，探索不同检测方法。
4. 鲁棒性评估：测试压缩、缩放及不同生成来源对检测效果的影响，避免训练集与测试集数据泄漏。
5. 原型开发：提供图像输入、检测结果展示与分析功能，具体方案由团队后续确定。

## 预期成果

- 图像真伪检测原型与可复现实验代码。
- 数据处理流程、实验记录与项目技术报告。
- 学术论文与软件著作权相关成果。

## 当前状态

项目筹备阶段，尚未发布检测模型、实验结果或可运行的应用。后续将逐步补充环境配置、数据说明、训练与推理方法。

## 使用边界

检测结果仅作为辅助判断依据，不应单独用于认定图像真实性或作出涉及个人的重大决定。团队应遵守数据许可，保护个人隐私，并记录模型的适用范围与局限。
