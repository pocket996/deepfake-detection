# 后续路线图

本文件记录 MVP 完成后的候选方向，不代表这些能力已经实现或承诺全部完成。当前执行基线以 [MVP.md](MVP.md) 为准。

## 当前阶段

完成公开 EEG 数据回放驱动的小车左右转闭环，优先保证可重复性、安全性和可演示性。

## 候选扩展顺序

1. 扩展到多个公开数据集和多个受试者，统一数据接口与评价脚本；
2. 增加跨 session 和 LOSO 评估，明确跨被试泛化上限；
3. 在相同数据划分下比较 CSP+LDA、FBCSP、EEGNet 等方法；
4. 研究少样本适配或特征对齐，但只在公开数据上验证；
5. 从左右二分类扩展到更多运动想象类别；
6. 为回放系统增加明确的 `NO_CONTROL` 数据与待机检测；
7. 增加障碍检测、共享控制和更完善的故障注入测试；
8. 完善实验追踪、自动化报告和硬件在环回归测试。

## 长期边界

- 不规划真人 EEG 采集、个人校准或真人在线实验；
- 不进行患者实验或载人测试；
- 不将公开数据回放称为真实在线脑机接口；
- 不依据单一准确率宣称系统具有医疗可用性；
- 所有新增方向必须在不削弱默认停车和硬件急停的前提下实施。

是否进入下一项扩展，以前一阶段有可重复代码、测试记录和结果报告为条件。
