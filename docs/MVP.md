# MVP 范围与验收

## 1. 目标

完成一个可重复演示的闭环原型：公开运动想象 EEG 数据按原始时间顺序回放，系统识别左手或右手运动想象，并控制小车执行一次短时左转或右转；当结果不可靠或系统异常时，小车保持或恢复停止。

本 MVP 验证的是工程链路，不宣称实现真实脑控轮椅或医疗产品。

## 2. 固定范围

### 包含

- 公开 EEG 数据集，第一选择为 BCI Competition IV 2b；
- 左手和右手运动想象二分类；
- 带通滤波、切窗、CSP 特征和 LDA 分类；
- 按 session 或 run 划分训练集和测试集；
- 按时间顺序进行数据回放和增量推理；
- 置信度门控与连续窗口确认；
- `LEFT`、`RIGHT`、`STOP` 三种控制结果；
- 串口或蓝牙通信；
- 固定时长、低速动作；
- 通信 watchdog、自动停车和物理急停；
- 可复现实验配置、结果、日志和演示视频。

### 不包含

- 真人 EEG 采集、校准或在线实验；
- 患者实验和载人轮椅；
- 第一阶段的四分类运动想象；
- 第一阶段的跨被试通用模型；
- 第一阶段的 EEGNet、DANN 等复杂模型；
- 将离线回放结果描述为真实在线 BCI 性能。

范围变更必须通过 Issue 讨论并由三名成员确认，不在开发过程中口头扩大 MVP。

## 3. 核心链路

```text
公开 EEG 数据
    ↓
数据读取与事件对齐
    ↓
滤波、切窗
    ↓
CSP + LDA
    ↓
置信度门控与连续窗口确认
    ↓
LEFT / RIGHT / STOP
    ↓
串口或蓝牙
    ↓
小车短时动作并自动停止
```

## 4. 里程碑

### M1：离线算法基线

交付：

- 可重复下载或准备公开数据的说明；
- 数据读取、预处理、训练和评估脚本；
- 至少一个受试者的 Balanced Accuracy、Kappa 和混淆矩阵；
- 数据划分和防止窗口泄漏的测试或检查记录。

通过条件：在全新环境中按照文档可以重现实验结果。

### M2：时间顺序回放

交付：

- 按原始时间顺序输出数据窗口的回放器；
- 增量预处理和分类接口；
- 每个窗口的时间戳、预测、置信度和计算延迟日志；
- 对数据结束、格式错误和处理中断的处理。

通过条件：回放结果可重复，且停止回放后不会继续产生移动命令。

### M3：小车独立可控

交付：

- 上位机手动控制脚本；
- 下位机命令解析与电机控制程序；
- 固定动作时长、通信超时 watchdog 和急停；
- 正常命令、非法命令、断连和超时测试记录。

通过条件：不连接分类器时，手动命令可稳定控制小车；停止发送后，小车能在记录的时间上限内自动停车。

### M4：软硬件闭环

交付：

- 数据回放到小车动作的完整集成；
- 指令、确认、延迟和异常日志；
- 多轮重复测试结果；
- 一段保留关键过程的演示视频。

通过条件：同一份测试数据可重复驱动小车完成预期的离散转向，并通过断连、低置信度和急停测试。

## 5. 总体验收指标

算法指标：

- Balanced Accuracy；
- Cohen's Kappa；
- 混淆矩阵；
- 每个受试者或 run 的独立结果；
- 训练和测试划分记录。

系统指标：

- 单次命令成功执行率；
- 分类输出到电机动作的延迟；
- 连续重复演示成功率；
- 通信中断后的自动停车时间；
- 非法命令拒绝率；
- 急停测试结果。

具体阈值由首轮基准测试确定，确定后写入配置和验收 Issue，不通过修改统计口径来追求结果。

## 6. 三人主责建议

- 数据与算法：数据读取、预处理、CSP+LDA 和评价；
- 实时与集成：时间回放、门控、日志和上位机通信；
- 硬件与安全：小车、下位机、watchdog 和急停。

主责不等于独占。每个 Pull Request 由另一方向的成员评审，每个里程碑至少进行一次三人集成测试。

## 7. 变更原则

以下内容可以在不改变 MVP 目标的前提下通过 Pull Request 调整：滤波范围、窗口长度、CSP 分量、LDA 参数、Python 库、主控型号和传输介质。

以下内容变更前必须先更新本文件：分类类别、数据来源、模块输入输出、安全行为、里程碑通过条件和最终演示形式。
