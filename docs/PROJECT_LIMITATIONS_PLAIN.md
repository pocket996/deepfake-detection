# 这个项目还差在哪里：大白话说明

现在已经能把照片、视频交给两个模型检查，也有给队友用的界面。但“能运行”和“对所有来源都可靠”是两件事。

## 1. 它学过一些出题老师，还没见过所有老师

整脸生成模型主要见过 FLUX 和 SD3.5。新的 GPT 版本、其他绘图工具、不同提示词和修图方法都可能变成陌生题。

**专业词：泛化能力。** 就是学过的东西换个场景后还能不能用。你的那张 GPT 图片识别成功，只能说明这个例子通过了，不能当作所有 GPT 图片的成绩。

怎么改：收集多个生成工具、不同真实照片来源；留出整种工具或整个来源，完全不参与训练和调参，再做考试。不要拿同一个生成器换几张图，就叫“全新来源测试”。

## 2. 它可能认的是拍照、修图习惯，而不是生成的破绽

如果真实照片大多是老照片，生成照片大多很干净，模型可能学成“干净就是假”。分辨率、压缩、背景风格、年龄和人脸位置，都可能成为取巧的线索。

**专业词：数据来源偏差、捷径学习。** 可以理解为考试时看校服猜学校，而没有真正做题。

我们已经对两类图片使用相同裁脸、尺寸和压缩处理，但这不能消除所有差异。怎么改：加入更多来源，用相似的质量和内容搭配真假样本；专门测试截图、聊天软件重压缩、缩小、模糊后的图片。

## 3. 同一个人、同一张图的近似副本，可能让考试变容易

同一张图只裁小一点、换个压缩格式，电脑可能把它当成两张。即使图片不同，同一人物或同一段原视频进入训练和测试，也可能让分数偏高。

**专业词：数据泄漏。** 相当于练习题和考试题悄悄用了同一份素材。

目前检查了精确重复和来源分组；LFW 能按人物分组，但 FFHQ 镜像没有完整人物信息。怎么改：先筛出相似图片供人工核查，按人物、原始素材及其所有派生图一起划分，不让一家人似的样本散进不同集合。

## 4. 99.8分不是99.8%的真实性概率

它是模型内部的一把尺子。尺子没有经过足够校准时，打到很高也可能判断错。

**专业词：阈值、校准、误报、漏报。** 阈值是分界线；校准是让分数与真实发生比例更接近；误报是把真图说成假图；漏报是没认出假图。

第一版模型在未见 SD3.5 上的排序分数看起来不错，但用固定分界线只认出了约18%的假脸。这说明“平均排名好看”和“实际判断好用”不等价。联合训练版后来改善了已知两种生成器，但仍需要外部考试。

怎么改：继续只用验证集定规则，同时报告有多少真图被误伤、有多少假图没认出；增加有验证依据的“不确定”结果。不要为了让某张图片过关，就临时挪分界线。

## 5. 视频检测像从电影里抽16张照片

模型目前没有连续看完整段动作。一个很短的换脸片段可能刚好落在抽样之间。

**专业词：时间采样、时序建模。** 前者是挑时间点取画面；后者才是学习前后画面怎样变化。

怎么改：按视频长度分段抽样，必要时增加帧数，报告可疑时间段；再比较能看前后变化的模型。整段 AI 生成视频还需要自己的数据与评估，不能拿换脸视频的成绩替代。

## 6. 一次主要看最大的一张脸，还会丢掉细节

多人画面里，小脸可能被忽略；侧脸、遮挡和模糊也可能找不到。生成检测还先把人脸缩到128像素，某些细小破绽会消失。

**专业词：多脸检测、多尺度。** 就是每张脸都检查，以及同时看整张脸和较细的局部。

怎么改：逐脸给结果，视频里跟踪同一张脸；比较多种尺寸和局部小块的检测效果。增加计算量是否值得，要用外部测试和实际速度决定。

## 7. 发布包能省安装步骤，不能省真实电脑验收

这次 Windows CPU 包把 Python、依赖和模型一起装进压缩包，队友不需要搭训练环境。但它不等于 macOS、Linux、手机都能用，也不等于每台 Windows 电脑都已经测试过。

**专业词：便携发布、兼容性、回归测试。** 分别是解压就能运行、换电脑能否正常用、改代码后旧功能有没有坏。

怎么改：让至少一台没有开发环境的队友电脑实际运行，再增加自动检查；记录版本、模型校验值和失败日志。后续每次发版都重复检查照片、视频、无脸、坏文件和移动目录这些场景。

## 改进顺序

先让队友稳定运行并收集失败情况；然后补多来源数据和真正独立的考试；接着完善误报、漏报和“不确定”处理；最后再升级更复杂的模型与视频能力。先把考试做可信，才知道换更大的模型有没有真正进步。
